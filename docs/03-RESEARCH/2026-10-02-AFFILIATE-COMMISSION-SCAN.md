# Varredura de Comissões — Gadgets, PC e Games

Data do snapshot: 2026-10-02.

## Objetivo

Comparar programas de afiliados relevantes para gadgets, informática e games.

O objetivo não é buscar somente a maior porcentagem nominal, mas a combinação:

Preço x Comissão x Conversão Potencial x Demanda x Compatibilidade de Aquisição

## Novo objetivo operacional

O agente deixa de procurar apenas "mais vendidos".

Passa a procurar:

> produtos com maior potencial de ganho como afiliado.

### Métricas

CRPS = Preço x Comissão

EAR = Preço x Comissão x Conversão Potencial

### Pipeline

-> 5 análises profundas
-> 3 elegíveis para teste
